# The Season That Changed Everything

Texas A&M 2006–07 men's basketball anniversary editorial. Local review edition for the 2027 anniversary, created October 19, 2026. Not an official university publication.

## Preview

From this directory: `python3 -m http.server 8767 --bind 127.0.0.1`
Open http://127.0.0.1:8767 . No install, framework, keys, or build required.

## Files

- index.html: complete original editorial and source links
- style.css: structural responsive rules
- future.css: futuristic minimalist redesign, glass navigation, monochrome typography, maroon lighting, responsive and reduced motion treatments
- data.js: all 34 official games, nine player profiles, five Kansas recap checkpoints
- app.js: season filters, selectable margins, cumulative records, player profiles, Kansas playback, progress
- assets/: archival images
- verify.cjs: data integrity checks (`node verify.cjs`)
- QA.md: validation results and limits
