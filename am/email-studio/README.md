# Texas A&M Athletics Email Studio

Open index.html in your browser for five complete email templates, 21 components and the design system. All files are local review artifacts.

Start with docs/START-HERE.md. Eloqua implementation: docs/ELOQUA.md. Source and browser check records are in validation-results.json and browser-validation.json.

For an HTTP preview, run `python3 -m http.server 8765 --bind 127.0.0.1` in this folder, then open http://127.0.0.1:8765. Stop with Control-C.

No email has been imported, sent or published. Replace all example.invalid links, remap images and complete account/client validation before production.
